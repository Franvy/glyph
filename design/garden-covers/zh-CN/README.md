# Chinese garden covers

Eight Chinese covers use the A4 portrait ratio, 210:297.

- `*.svg`: vector covers at 210 × 297 mm, with embedded fonts.
- `*.png`: 1680 × 2376 px covers.
- `overview.png`: all eight covers on one sheet.
- `index.html`: a local gallery.
- `manifest.json`: Chinese copy, colours and sequence numbers.

Run `pnpm garden:covers:zh` to rebuild this edition. Run `pnpm garden:covers`
first if the shared scene art has changed.

The Chinese copy uses Noto Sans SC. The bundled WOFF2 files contain only the
characters used by these covers. Numbers use Paper Mono. Both fonts use the
SIL Open Font License. See [`fonts/OFL.txt`](fonts/OFL.txt) and
[`PaperMono-OFL.txt`](../../../src/assets/fonts/PaperMono-OFL.txt).

The editable Paper edition is on the page
[煤球的花园 · A4 中文封面](https://app.paper.design/file/01M5CQPR61BKWR6XPF8GCN76GF/p-3-0).
